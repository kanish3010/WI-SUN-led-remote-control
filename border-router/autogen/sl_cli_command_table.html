wisun pan_defect_advertise u8 u32 u32 app_pan_defect_advertise
Set PAN defect advertisement
Alias w pan_defect_advertise
Arguments
  • u8defect_advertise: True to start PAN Defect procedure, false to stop it
  • u32minimum_scan_time_s: Minimum duration after which devices are allowed to switch their PAN if an alternative one is available.
  • u32maximum_scan_time_s: Duration after which devices should systemically switch to the alternative PAN if one is available.
